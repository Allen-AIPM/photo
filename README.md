# 素材灵感库 · Allen专属

基于原灵感库的 18 张图片与数据制作，保留原页面暖白与陶土橙风格、瀑布流、大图详情、搜索筛选、收藏、下载原图和访问原址，新增全屏首页、固定半透明导航栏和图片评论。

## 运行

推荐 Node.js 22.16.0，项目附带版本文件。支持 Node.js 22.12+ 至 24.x。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。也可以双击 `启动预览.cmd`。关闭对应终端可停止服务。

## 构建

```sh
npm run build
npm run preview
```

## 数据与范围

- `src/data.json`：原文件夹 data.js 的数据快照；`public/image`：原始图片副本。
- `src/main.jsx`：React 页面与交互；`src/style.css`：原版样式；`src/upgrade.css`：新增首页和适配样式。
- 原始文件夹中的 HTML、Excel 和脚本未作修改。
- 收藏和评论使用浏览器本地存储；评论支持发布和删除，刷新后保留。当前基础版没有账号或服务器，多设备、多浏览器之间不共享评论。
- 浏览器禁用或清除网站存储会影响本地记录。旧版 HTML 与新版本使用不同地址时，旧收藏不会自动跨地址迁移。
- 素材是创建时的快照，之后修改原 Excel 或添加图片不会自动同步到此项目。
- PC 优先，内容区域最大约 1700px，窄屏有基础适配。

## 动效

本版本已完成图片、动效和首页加载优化。详细结果见 `PERFORMANCE.md`。

根据提供的 React Bits JavaScript + CSS 源码接入五个组件，位于 `src/components/`：

- FoldText：首页两行标题逐字折叠入场。
- TargetCursor：图片和可用按钮、链接的悬停锁定，兼容详情弹窗。
- GlowCursor：陶土橙鼠标光迹，停留后淡出，仅在精细鼠标设备启用。
- SpecularButton：首页探索、详情收藏、发布评论按钮的光泽边缘。
- Stack：首页四张现有素材，支持拖拽、点击以及 Enter/空格切换。

依赖 `gsap`、`ogl`、`motion`。Stack 样式使用独立类名，不影响原瀑布流卡片。尊重系统的减少动态效果偏好；不支持 WebGL 时保留普通按钮。原生鼠标继续可用。
